# История изменений

Здесь записываются изменения в каждом релизе. Новые изменения
добавляются в раздел «Не выпущено». При выпуске он переименовывается
в номер версии с датой.

Изменения до версии 1.1.5 включительно — на странице
[релизов GitHub](https://github.com/petrovich/petrovich-ruby/releases).

## Не выпущено

### Главное: составные фамилии и имена

Фамилии из нескольких слов теперь склоняются по словам, через дефис и
через пробел. Служебные частицы при этом не склоняются. Разделители между
словами сохраняются как есть.

| Было | Стало |
|---|---|
| Лопес Обрадора | Лопеса Обрадора |
| Роналду душ Сантуш Авейру | Роналду душ Сантуша Авейру |
| Родригес де Сильва Веласкеса | Родригеса де Сильвы Веласкеса |
| Иванов - Петрова | Иванова - Петрова |
| Заяца | Зайца |

В двойном имени по норме склоняется только последняя часть:

| Было | Стало |
|---|---|
| Жана-Поля | Жан-Поля |
| Анны-Марии, Анне-Марии | Анна-Марии |

> ⚠️ Это меняет результат для всех двойных имён (Анна-Мария,
> Мария-Луиза, Жан-Поль и т. п.). Если вы сохраняли или сравнивали
> прежние формы, проверьте их.

Правила (сабмодуль `rules`):

- новые несклоняемые частицы: дер, ла, де, да, душ, ле, сент, грум, кара;
- беглая гласная в «заяц» и «отец»;
- Баба-Яга склоняет обе части;
- имена Пенелопа и Урсула определяются как женские (раньше — `androgynous`).

### Исправления

- `male?`, `female?`, `androgynous?` учитывают явно переданный `gender`,
  а не только определённый по имени.
- `Name#to_s` больше не добавляет лишние пробелы, если части ФИО нет
  (`" Иван "` → `"Иван"`).
- Определён класс `Petrovich::UnknownCaseError`: раньше на его месте
  возникал `NameError`.
- `Case::Rule` больше не теряет теги правил.
- Имя нормализуется до проверки.
- Исполняемый файл `bin/petrovich` теперь входит в gem.
- `CHANGELOG.md` теперь входит в gem.
- CLI больше не использует `OpenStruct`, поэтому работает на Ruby 3.4+
  без предупреждений.
- `File.exists?` заменён на `File.exist?`.
- Если сабмодули с правилами не загружены, выводится понятное сообщение.
- Исправлены примеры в README.

### Тесты и разработка

- Юнит-тесты для внутренних классов, публичного API и gemspec.
- Интеграционные тесты для CLI и rake-задач.
- Отчёт о покрытии строк: 100%. Задача `rake coverage` запускает тесты
  с отчётом и проверяет порог покрытия (`COVERAGE_MIN`, по умолчанию 95%).
- `csv` добавлен в dev-зависимости.
- В README новый раздел о составных фамилиях и именах.
